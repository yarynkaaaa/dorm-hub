# DormHub: план проєкту

## 1. Назва та опис

**DormHub** — веб-сайт для управління студентським гуртожитком. Застосунок веде облік мешканців і кімнат, фіксує поселення та виселення, а також контролює оплату проживання.

**Мета:** замінити паперові журнали й таблиці єдиною системою, у якій комендант швидко бачить вільні місця, поселяє й виселяє мешканців та контролює борги.

## 2. Ролі

| Роль          | Можливості                                                          |
| ------------- | ------------------------------------------------------------------- |
| Адміністратор | Керує акаунтами та ролями, має повний доступ до всіх даних і звітів |
| Комендант     | Переглядає кімнати, поселяє й виселяє мешканців, веде облік оплат   |
| Мешканець     | Переглядає власну кімнату та історію своїх оплат                    |

## 3. Вимоги

### Функціональні

- Перегляд списку кімнат із кількістю вільних місць і статусом заповнення.
- Облік мешканців: ПІБ, факультет, група, контакти.
- Поселення мешканця в кімнату з перевіркою наявності вільних місць.
- Виселення мешканця із фіксацією дати.
- Облік оплат проживання та перелік боржників.
- Вхід у систему та розмежування доступу за ролями.
- Пошук і фільтрація (за кімнатою, поверхом, статусом, мешканцем).

### Нефункціональні

- Інтерфейс працює в сучасних браузерах і коректно відображається на ПК та телефоні.
- Проєкт запускається однією командою як локально, так і в Docker-контейнері.
- Паролі зберігаються лише у вигляді хешів, доступ до даних перевіряється за роллю.
- Код організований за частинами: дані, компоненти, сторінки.

| №   | Сценарій                                             | Роль      | Стан                                |

| 1   | Перегляд кімнат і наявності вільних місць            | Комендант | Реалізовано в Л 1.1 (дані-заглушка) |

| 6   | Перегляд власної кімнати й оплат                     | Мешканець | Заплановано                         |

### Реалізований сценарій (Л 1.1)

Комендант відкриває головну сторінку й бачить перелік карток кімнат. Кожна картка показує номер, поверх, місткість, кількість зайнятих місць і статус: «Вільна», «Є вільні місця» або «Заповнена». Угорі сторінки відображається загальна кількість вільних місць.

## 5. Попередня модель даних

| Сутність                  | Основні поля                                           |
| ------------------------- | ------------------------------------------------------ |
| Resident (мешканець)      | id, ПІБ, факультет, група, телефон                     |
| Room (кімната)            | id, номер, поверх, місткість                           |
| Accommodation (поселення) | id, мешканець, кімната, дата заселення, дата виселення |
| Payment (оплата)          | id, мешканець, сума, період, дата, статус              |
| User (акаунт)             | id, логін, хеш пароля, роль                            |

## 6. Технології

- **Frontend:** React (Vite), JavaScript.
- **Середовище:** Node.js (LTS), npm, Git, Docker, Visual Studio Code.
